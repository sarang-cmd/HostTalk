# Changelog

Notable changes per release. Earlier releases are in the git history.

## 2.2.0 Roll call

### People

- A blank name joins as John Appleseed. The next guest becomes John Appleseed 2.
- A browser keeps its name, picture, role, and badge on the server.
- Profile pictures up to 3 MB, with initials as the fallback.
- Roles: host, moderator, member. The first person in the room is the host.
- A badge of one icon and up to four characters, picked by each person.

### Messages

- The message toolbar floats above the row and appears on hover, with a divider before delete.
- Any emoji works as a reaction.
- The host adds custom emoji pictures. Everyone reacts with them.
- Host and moderators pin messages. The pinned sheet jumps back to the source.
- A short tone plays when a message leaves, and another when one arrives.

### Rooms

- Rooms sit inside rooms. Each level can carry its own password.
- The rail indents by depth and shows the rooms under a room you joined.
- The color palette stays at twenty steps with a contrast check on each.

### Host

- A host name and a host password, separate from the join password, changed on the hosting machine only.
- Lock the room, set read only, set slow mode, and post a notice.
- Role changes from the console, including the host role.
- GIF search moves from GIPHY to KLIPY.

### App

- A desktop build with a control window and an app style browser window.
- A new mark for the window, the browser tab, and the installer.
- Builds for Windows, macOS, and Linux, attached to a tag.

## 2.1.0 Roomtone

- Group rooms, direct threads, invite links, and per person colors.
- Quoting, reactions, edit and delete, search, and link previews.
- File uploads, client side compression, and LocalSend interop.
- The host console with checks, logs, backups, and a stop button.
