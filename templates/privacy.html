Privacy note

HostTalk keeps data on the machine that hosts the room. This note lists what is stored, where it goes, and how the host removes it.

What the host machine stores

  • Display names, an internal user id, an assigned color, and a device key per name.
  • Messages, quoted messages, reactions, room names, and direct thread membership.
  • Files you upload, with the original filename, content type, size, and a SHA-256 digest.
  • Password hashes for the room and for locked direct threads. HostTalk uses bcrypt and stores no plain passwords.
  • A log of display name changes with the time and the requesting IP address.
  • Technical logs with timestamps, log level, event name, and sometimes a user name, room name, or IP address.
  • Configuration in config.json, including the port, room name, and an optional GIPHY key.

What your browser stores

  • A signed session cookie. It is HttpOnly and SameSite=Lax, and it lasts up to 30 days.
  • Your display name, device key, theme choice, sound choice, and per-room draft text in local storage.
  • Recent room markers for unread counts.

What leaves the local network

  • Nothing, during normal chat. Messages move between your browser and the host over the local network.
  • GIF search sends the search words to GIPHY through the host, only when someone searches. The API key stays on the host.
  • Link previews fetch the linked page from the host. The page sees the host's address and a generic browser user agent.
  • LocalSend exchanges files with devices on the same network. Those devices see the host's alias, fingerprint, and IP address.

Analytics and advertising

There are none. The project ships no analytics, no advertising code, and no third-party tracking scripts. Fonts are served from the host.

How long data stays

The host decides. Messages stay in SQLite until someone clears the room or removes the database. Logs rotate at 2 MB with three backups. Uploaded files stay until the data folder is cleaned. The host can export messages as JSON and clear rooms in the console.

Security limits

Traffic inside the local network is plain HTTP. Someone who watches the network sees message text and uploaded files. Password hashes and the session cookie are not readable from the page, but they are not a substitute for network security. Run HostTalk on a network and machine you trust.

Your choices

Ask the host of your room to correct or delete your entries. The host removes a name, its messages, and its files from the data folder. The host also controls the room password, the log level, and whether link previews and GIF search are on.

Before publishing

Add the contact address for the operator of this deployment and confirm retention practice with them. Review the text with a qualified person for your jurisdiction.
