How a message travels

Three steps, one machine. HostTalk serves the app, checks the room password, stores each message in SQLite, and pushes new messages to open browsers over one long-lived connection.

  1. One host

    A laptop, desktop, or small server starts HostTalk. The app, the database, and uploaded files live on one disk.

  2. Same Wi-Fi

    A guest opens the address and enters a name plus the room password. The browser holds a signed session cookie.

  3. Stored here

    A message is written to the database and streamed to every open browser. No third-party service carries the text.

What the server keeps, and where

The host machine holds every message, file, and log. The browser holds a session cookie, a display name, a device key, and your appearance settings in local storage.

Rooms and direct threads

One main room for the network. Named rooms hold up to 20 people and can sit inside one another, each with its own password. Direct threads stay private between two people.

Names, pictures, and badges

A browser keeps its name, picture, role, and badge. Someone who joins without a name becomes John Appleseed. Badges carry one icon and up to four characters.

Files up to 20 MB

Images render in the thread. Other files download as attachments. The browser compresses an oversized image before upload, and the server checks the limit again.

Quotes, reactions, edits

Reply to a message with its quote attached. React with any emoji, or with pictures the host adds. Edit or delete your own messages; the room keeps a quiet placeholder.

Link previews with a guard

The server fetches a page title and image when someone posts a link. Requests to private addresses are refused, so a preview cannot probe the network.

GIF search when you add a key

Search goes through the server to KLIPY. The key stays on the host. GIF search is off until a key is added in the console.

LocalSend devices

Phones and computers running LocalSend appear after a scan. Files they send land in the main room. Received files follow the same 20 MB limit.

A console for the host

Checks, settings, logs, people, rooms, and exports, plus room controls and a stop button. A host name and host password open it, and it listens on this machine only by default.

SQLite and JSON logs

The database runs in WAL mode. Logs rotate at 2 MB with three backups. Nothing ships to an analytics service.

What it does not do

These limits are part of the design. Knowing them makes the tool easier to trust.

No accounts
A name and a device key hold your place. Someone with the room password on a new device picks a name and joins. The host keeps a log of name changes.
No end-to-end encryption
Traffic is plain HTTP inside the local network. The machine hosting the room stores message text in SQLite and reads it. Run HostTalk on hardware you control.
No relay across networks
Guests outside the Wi-Fi need a VPN or a tunnel you set up. HostTalk does not offer one, and it does not reach the internet to deliver messages.
No cloud backup
Copy the data folder to back up messages and uploads. Clearing a room in the console deletes its messages for good.
Third-party requests are explicit
A GIF search sends the words to KLIPY. A link preview fetches the page from the host. Nothing else leaves the network unless you post a link.

Run it yourself

Python 3.10 or newer. Two commands on the host, one browser window for setup. The console sets the password, port, and LocalSend preference.

From source

python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS and Linux:
source .venv/bin/activate
pip install -r requirements.txt
python server.py

Then open http://127.0.0.1:7284/console on the host.

Options

--port 8080Listen on another port. Config also stores it.
--host 127.0.0.1Keep the room on one machine.
--data-dirMove the database, uploads, and logs.
--headlessDo not open a browser. Use with a service.
--no-localsendTurn discovery off for this run.
appStart the room with the desktop window.
setupSet the password without the browser.
doctorCheck the network, port, and data folder.
configRead or set a value in config.json.

Service files for systemd, launchd, Docker, and Windows live in the deploy folder. A compose file starts HostTalk with a fixed data volume.

On a phone and in the console

The room fits a phone without a separate app. The console gives the host one screen for checks, settings, logs, and people.
